LOOPERS 비공식 한국어 패치 v1.0.1 — 수동 설치판

지원: Steam 앱 1811500 / 게임 빌드 25823497 / Windows x64

[설치]
1. 게임을 종료하고 기존 다른 패치나 모드를 원본으로 복구합니다.
2. Steam 라이브러리 → LOOPERS → 관리 → 로컬 파일 탐색으로 게임 폴더를 엽니다.
3. 덮어쓸 원본 파일을 게임 폴더 밖에 별도로 백업합니다.
4. ZIP의 '패치파일' 폴더 안의 파일과 폴더를 LOOPERS.exe가 있는 곳에 복사하고 덮어씁니다.
   '패치파일' 폴더 자체를 복사하는 것이 아닙니다.
5. 게임 언어를 일본어로 설정합니다. 해당 언어의 내용이 한국어로 표시됩니다.

[제거]
게임을 종료하고 백업한 원본을 복원한 뒤 이 패치가 추가한 version.dll을 제거합니다.
백업이 없다면 해당 DLL을 제거하고 Steam → 설치된 파일 → 게임 파일 무결성 검사를 실행합니다.
세이브나 다른 모드의 파일은 삭제하지 마세요. 수동 설치는 자동 설치기의 복구 기록을 만들지 않습니다.

[적용이 안 될 때]
- 게임 빌드가 지원 버전인지, 올바른 게임 폴더에 모든 패치 파일을 복사했는지 확인하세요.
- 게임 언어가 일본어인지 확인하세요. 자동 패치와 수동 패치를 섞어 설치하지 마세요.
- Windows가 실행을 차단하는 경우: 패치의 version.dll은 미서명 파일이므로 스마트 앱 컨트롤에서 차단될 수 있습니다.
  수동 설치도 이 제한을 받습니다. 오류 문구와 함께 문의해 주세요.

게임 실행·표시 문제는 게임 폴더의 luckproxy.log와 해당 화면을 함께 알려주세요.
게임 업데이트 후에는 새 빌드의 패치 지원 여부를 확인하세요.

정품 게임이 필요한 비공식·비상업적 팬패치이며 원작자·개발사·배급사와 무관합니다.
동봉된 제3자_라이선스_고지.txt를 확인하세요.
