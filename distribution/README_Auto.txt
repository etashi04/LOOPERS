LOOPERS 비공식 한국어 패치 v1.0.1 — 자동 설치판

지원: Steam 앱 1811500 / 게임 빌드 25823497 / Windows x64

[설치]
1. 게임을 종료하고 ZIP 전체를 별도 폴더에 압축 해제합니다.
2. LOOPERS_Korean_Patch_v1.0.1.exe를 실행합니다.
3. LOOPERS.exe가 있는 게임 폴더를 선택하고 [한국어 패치 설치]를 누릅니다.
   Steam 라이브러리 → LOOPERS → 관리 → 로컬 파일 탐색으로 위치를 확인할 수 있습니다.
4. 게임 언어를 일본어로 설정합니다. 해당 언어의 내용이 한국어로 표시됩니다.

기존 v1.0.1 자동 설치판은 설치 기록과 파일이 일치하면 그대로 갱신됩니다.
다른 버전이나 수동 패치를 사용 중이라면 먼저 원본으로 복구하세요.

[제거]
게임을 종료한 뒤 이번 설치기에서 같은 게임 폴더를 선택하고 [원본 복구]를 누릅니다.
게임 폴더의 _LOOPERS_KR_PATCH_v1.0.1 및 원본백업은 복구 전까지 보존하세요.
세이브 파일은 수정하지 않습니다.

[설치가 안 될 때]
- 폴더 오류: 압축을 푼 폴더가 아니라 LOOPERS.exe가 있는 게임 폴더를 선택하세요.
- 원본 불일치: 지원 게임 빌드와 이전 패치 여부를 확인하세요. 이전 자동 패치는 해당 설치기로 복구합니다.
  수동 패치는 원본을 복원하고 추가된 version.dll을 제거합니다. Steam 무결성 검사만으로 이 DLL이 제거되지는 않을 수 있습니다.
- 권한·파일 사용·공간 오류: 게임과 다른 설치기를 종료하고, 안내된 쓰기 권한과 여유 공간을 확인하세요.
- Windows가 실행을 차단하는 경우: 이 패치의 EXE와 DLL은 미서명 파일이므로 스마트 앱 컨트롤에서 차단될 수 있습니다.
  수동 설치로 같은 DLL의 실행 차단이 해결되지는 않습니다. 오류 문구와 함께 문의해 주세요.

설치 오류의 진단 로그 위치는 오류 창에 표시됩니다(기본: %TEMP%\LOOPERS_KR_Patch).
게임 실행·표시 문제는 게임 폴더의 luckproxy.log와 해당 화면을 함께 알려주세요.
불완전한 설치 기록이 남았다면 백업·임시 폴더를 보존하고 문의하세요.

정품 게임이 필요한 비공식·비상업적 팬패치이며 원작자·개발사·배급사와 무관합니다.
동봉된 제3자_라이선스_고지.txt를 확인하세요.
