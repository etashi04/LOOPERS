# LOOPERS 한국어 패치

Steam판 **LOOPERS** 비공식 한국어 패치 저장소입니다.

현재 정식 배포 버전은 `v1.0.1`이며 Steam 앱 ID `1811500`, 게임 빌드 `25823497`, Windows x64 환경에서 확인했습니다.

## 배포본

[최신 릴리스](https://github.com/etashi04/LOOPERS/releases/latest)에서 다운로드할 수 있습니다.

- `LOOPERS_Korean_Patch_v1.0.1.zip`: GUI 설치기를 통한 자동 설치·원본 복구
- `LOOPERS_Korean_Patch_Manual_v1.0.1.zip`: 게임 실행 파일이 있는 폴더에 직접 복사
- `SHA256SUMS.txt`: 배포 ZIP 무결성 확인용 체크섬

게임을 종료한 상태에서 설치하세요. 자동판에는 설치 EXE와 설치 안내문, 수동판에는 패치파일 폴더와 수동 전용 안내문이 포함되며, 두 배포본 모두 제3자 고지를 제공합니다.

## 자동 설치

1. 자동 설치 ZIP을 모두 압축 해제합니다.
2. `LOOPERS_Korean_Patch_v1.0.1.exe`를 실행합니다.
3. **찾아보기**로 `LOOPERS.exe`가 있는 게임 폴더를 선택하고 **한국어 패치 설치**를 누릅니다.
4. 게임을 실행하고 언어를 **일본어**로 설정합니다.

## 수동 설치

1. 수동 설치 ZIP의 `패치파일` 폴더를 엽니다.
2. 덮어쓸 원본 파일을 먼저 백업합니다.
3. 안의 모든 파일과 폴더를 `LOOPERS.exe`가 있는 경로에 복사하여 병합·덮어씁니다.
4. 게임을 실행하고 언어를 **일본어**로 설정합니다.

## 복구

- 자동판: 같은 설치기에서 같은 게임 폴더를 선택하고 **원본 복구**를 누릅니다. `_LOOPERS_KR_PATCH_v1.0.1` 폴더는 복구 전까지 삭제하지 마세요.
- 수동판: 자동 복구 기록이 생성되지 않습니다. 수동 설치 ZIP의 `README.txt`에 따라 제거하고 백업한 원본을 복원하세요.

## 오류 해결

### 스마트 앱 컨트롤이 설치기 또는 게임 실행을 차단할 때

이 패치의 설치 EXE와 `version.dll`은 디지털 서명이 없어 Windows 스마트 앱 컨트롤에서 차단될 수 있습니다. 오류 안내에서 스마트 앱 컨트롤에 의한 차단인지 먼저 확인하세요.

해당 기능이 차단 원인이라면 아래 설정을 끈 뒤 다시 실행할 수 있습니다. **이 설정은 PC 전체의 앱 실행 보호 수준을 낮추므로 변경 여부는 사용자가 판단해 주세요.** 변경 전 화면에 표시되는 재활성화 관련 안내도 확인하세요.

1. **Windows 보안**을 엽니다.
2. **앱 및 브라우저 컨트롤 → 스마트 앱 컨트롤 설정**으로 이동합니다.
3. 설정 변경을 선택한 경우 **끄기**로 바꾼 뒤, 차단됐던 설치기 또는 게임을 다시 실행합니다.

설치 EXE만 차단된다면 **수동 설치판**을 이용할 수 있습니다. 다만 게임이 불러오는 `version.dll` 자체가 차단되면 **수동 설치로도 해결되지 않습니다.**

차단 원인이 다르거나 문제가 계속되면 오류 문구와 차단된 파일명을 확인한 뒤, 저장소의 [이슈(Issues) 탭](https://github.com/etashi04/LOOPERS/issues)에 제보해 주세요. 로그·스크린샷을 공개할 때는 사용자 이름과 개인 경로를 가려 주세요.

## 주의

- 원작자·개발사·배급사와 무관한 비공식 한국어 팬 패치입니다.
- 게임 업데이트 후 호환되지 않을 수 있습니다.
- 배포 파일은 `SHA256SUMS.txt`로 무결성을 확인할 수 있습니다.
- 정품 게임이 필요하며 비상업적으로 제작된 패치입니다.
- 게임 원본, 추출 데이터, 빌드 산출물, 개인 경로 및 내부 작업 기록은 저장소에 포함하지 않습니다.
- 이전 버전이나 수동 패치가 설치되어 있다면 먼저 원본으로 복구하세요. 설치 폴더는 `LOOPERS.exe`가 있는 경로를 선택합니다. 자세한 문제 해결 방법은 ZIP의 `README.txt`를 확인하세요.
- Windows 스마트 앱 컨트롤에서 실행이 차단될 때는 위의 [오류 해결](#오류-해결) 안내를 확인하세요.
- 제3자 구성요소의 라이선스는 `THIRD_PARTY_NOTICES.txt`를 확인하세요.
