## 배포본

[최신 릴리스](https://github.com/etashi04/LOOPERS/releases/latest)에서 다운로드할 수 있습니다.

- `LOOPERS_Korean_Patch_v1.0.0.zip`: GUI 설치기를 통한 자동 설치·원본 복구
- `LOOPERS_Korean_Patch_Manual_v1.0.0.zip`: 게임 실행 파일이 있는 폴더에 직접 복사
- `SHA256SUMS.txt`: 배포 ZIP 무결성 확인용 체크섬

게임을 종료한 상태에서 설치하세요. 자동판에는 설치 EXE와 설치 안내문, 수동판에는 패치파일 폴더와 수동 전용 안내문이 포함되며, 두 배포본 모두 제3자 고지를 제공합니다.

## 자동 설치

1. 자동 설치 ZIP을 모두 압축 해제합니다.
2. `LOOPERS 한국어 패치 v1.0.0.exe`를 실행합니다.
3. **찾아보기**로 `LOOPERS.exe`가 있는 게임 폴더를 선택하고 **한국어 패치 설치**를 누릅니다.
4. 게임을 실행하고 언어를 **일본어**로 설정합니다.

## 수동 설치

1. 수동 설치 ZIP의 `패치파일` 폴더를 엽니다.
2. 덮어쓸 원본 파일을 먼저 백업합니다.
3. 안의 모든 파일과 폴더를 `LOOPERS.exe`가 있는 경로에 복사하여 병합·덮어씁니다.
4. 게임을 실행하고 언어를 **일본어**로 설정합니다.

## 복구

- 자동판: 같은 설치기에서 같은 게임 폴더를 선택하고 **원본 복구**를 누릅니다. `_LOOPERS_KR_PATCH_v1.0.0` 폴더는 복구 전까지 삭제하지 마세요.
- 수동판: 자동 복구 기록이 생성되지 않습니다. 수동 설치 ZIP의 `README.txt`에 따라 제거하고 백업한 원본을 복원하세요.

## 주의

- 정품 게임이 필요하며, 원작자·개발사·배급사와 무관한 비공식·비상업적 팬 패치입니다.
- 게임 원본, 추출 데이터, 빌드 산출물, 개인 경로 및 내부 작업 기록은 저장소에 포함하지 않습니다.
- 게임 업데이트 후 호환되지 않을 수 있습니다.
- Windows에서 알 수 없는 앱 경고가 표시될 수 있습니다. 배포 파일은 `SHA256SUMS.txt`로 무결성을 확인할 수 있습니다.
- 제3자 구성요소의 라이선스는 `THIRD_PARTY_NOTICES.txt`를 확인하세요.
