# LOOPERS 비공식 한국어 패치

게임 **LOOPERS**의 비공식 한국어 패치 저장소입니다.

## 설치 방법

1. [최신 릴리즈](https://github.com/etashi04/LOOPERS/releases/latest)에서 `LOOPERS_Korean_Patch_v1.0.0.zip`을 다운로드합니다.
2. 다운로드한 ZIP의 압축을 풉니다.
3. LOOPERS를 완전히 종료합니다.
4. 압축을 푼 폴더의 `LOOPERS 한국어 패치 v1.0.0.exe`를 실행합니다.
5. **찾아보기**로 `LOOPERS.exe`가 있는 게임 설치 폴더를 선택하고 **한국어 패치 설치**를 누릅니다.
6. 게임을 실행하고 언어를 일본어로 설정하면 한국어 패치가 적용됩니다.

원본 상태로 되돌리려면 같은 EXE를 다시 실행하고 같은 폴더를 선택한 뒤 **원본 복구**를 누릅니다. 설치할 때 생성된 `_LOOPERS_KR_PATCH_v1.0.0` 폴더는 복구 전까지 삭제하지 마세요.

Windows에서 알 수 없는 앱 경고가 표시될 수 있습니다. 배포 파일은 릴리즈에 함께 제공되는 `SHA256SUMS.txt`로 무결성을 확인할 수 있습니다.

자동 설치 EXE를 사용할 수 없다면 `LOOPERS_Korean_Patch_Manual_v1.0.0.zip`을 받으세요. `패치파일` 안의 모든 파일과 폴더를 게임 설치 폴더에 복사하여 병합·덮어씁니다. 덮어쓸 원본은 반드시 먼저 백업하세요. 수동 설치는 자동 복구 기록을 만들지 않습니다. 제거 방법은 해당 ZIP의 README.txt를 확인하세요.

## 저장소 구성

- 설치기 소스와 빌드 도구: `distribution/`, `build_release.ps1`
- 버전별 지원 정보·원본 및 패치 해시: `versions/`
- 변경 사항: `CHANGELOG.md`
- 제3자 라이선스: `THIRD_PARTY_NOTICES.txt`

게임 원본, 추출 데이터, 빌드 산출물, 개인 경로 및 내부 작업 기록은 저장소에 포함하지 않습니다.

## 배포본

현재 패치 버전은 `VERSION`에서 관리합니다. 자동 설치판, 수동 설치판, SHA-256 체크섬을 함께 배포합니다.

- 자동 ZIP: 패치 데이터를 내장한 설치 EXE, README.txt, 제3자 고지
- 수동 ZIP: 패치파일 폴더, 수동 전용 README.txt, 제3자 고지
- `SHA256SUMS.txt`: 자동·수동 설치판의 SHA-256 무결성 정보

지원 게임은 Steam 앱 ID 1811500, 빌드 14841524, Windows x64입니다. 정품 게임이 필요합니다. 비공식·비상업적 팬패치이며 원작자·개발사·배급사와 무관합니다.

## 새 버전 배포

1. `VERSION`, `versions/`의 지원 정보와 해시, `CHANGELOG.md`를 갱신합니다.
2. 검증된 패치 묶음과 승인된 설치기 이미지 자산을 별도로 준비합니다. 이 저장소에는 게임 데이터가 포함되지 않습니다.
3. `build_release.ps1`로 내장형 설치 EXE를 빌드합니다.
4. 자동·수동 ZIP 작성 후 순정 게임에서 설치·복구·실행을 검증하고 체크섬을 생성합니다.

초기 설치기 시험에서 재설치 실패가 1회 있었으나 이후 설치·복구 3회 반복에서는 재현되지 않았습니다. 원인은 미확정입니다. 긴 경로·고배율·강제 중단 복구와 게임 내 저화질 영상 재생은 아직 검증되지 않았습니다. 저화질 영상 파일의 전체 디코딩 및 음성 동일성 검사는 통과했습니다.
